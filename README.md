# 🍽️ Zomato Restaurant Recommendation & Rating Prediction System

This project recommends restaurants based on City, Cuisine and Budget using the Zomato dataset. It also predicts the expected restaurant rating using a Random Forest Machine Learning model.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Features
- Restaurant Search
- Restaurant Details
- Rating Prediction
- Google Maps Link
- Similar Restaurants
